# Scripts

Denne mappen inneholder skript som fortsatt er relevante for den endelige
løsningen.

- `run_reachy_realtime.py`: starter Reachy Mini-varianten av løsningen
- `normalize_rag_sources.py`: normaliserer tekstkilder for lokal RAG
- `normalize_rag_sources.ps1`: PowerShell-variant av samme normalisering
- `smoke_test_motion.py`: enkel manuell test av Reachy-bevegelse
- `smoke_test_record.py`: enkel manuell test av lydopptak fra Reachy Mini

Eldre prototype- og eksperimentelle skript er fjernet fra leveringsversjonen.
